Claude Code 설치 가이드

VS Code에서 Claude Code를 실행하기 위한 단계별 설정 안내입니다.

시작 전, 이 도구들이 뭔가요?

설치 단계에서 등장하는 프로그램들의 역할을 한 줄로 요약했습니다.

Node.js 필수

자바스크립트 실행 환경. Claude Code가 내부적으로 Node.js 위에서 동작합니다.

Git 필수

코드 변경 이력을 관리하는 도구. Claude Code가 변경 사항을 추적·되돌리는 데 사용합니다.

VS Code 필수

Microsoft의 무료 코드 에디터. Claude Code 확장 프로그램이 이 위에서 실행됩니다.

Python 선택

데이터 분석·자동화에서 가장 많이 쓰이는 프로그래밍 언어. 필수는 아니지만 미리 설치해두면 편합니다.

Claude Code 필수

Anthropic이 만든 AI 코딩 도구. VS Code 확장으로 설치하면 채팅창에서 코드 작성·수정·실행을 맡길 수 있습니다.

4. VS Code 설치

필수

Claude Code를 실행할 코드 에디터입니다. 인스톨러(.exe)를 실행하면 설치 마법사가 진행됩니다. "Add to PATH" 옵션은 기본 체크되어 있으니 그대로 두고 진행하세요.

Claude Code를 실행할 코드 에디터입니다. 다운로드한 .zip 파일을 더블클릭해 압축을 풀고, Visual Studio Code.app을 Applications 폴더로 드래그하면 설치 완료입니다. (Apple Silicon / Intel 칩셋에 맞는 파일을 받으세요)

5. VS Code 환경 설정

선택 단계

한국어 언어팩과 컬러 테마를 설정하면 화면이 더 편해집니다.

한국어 언어팩 설치

  1. VS Code 왼쪽 사이드바의 확장(Extensions) 아이콘을 클릭합니다. CtrlCmd + Shift + X
  2. 검색창에 Korean을 입력합니다.
  3. 아래와 같은 항목을 찾아 Install 버튼을 누릅니다.
Korean Language Pack for Visual Studio Code 제작자 Microsoft
  1. 오른쪽 아래 안내에 따라 Restart를 눌러 VS Code를 다시 시작합니다.

컬러 테마 변경

  1. VS Code 상단 가운데 검색창을 클릭하거나 CtrlCmd + Shift + P를 누릅니다.
  2. 검색창에 >color theme를 입력하고 기본 설정: 색 테마(Preferences: Color Theme)를 선택합니다.
  3. 방향키 ↑↓로 미리보기를 확인하고 마음에 드는 테마에서 Enter를 눌러 적용합니다.

  2. 검색창에 Claude Code를 입력합니다.
  3. 아래와 같은 항목을 찾아 Install 버튼을 누릅니다.
Claude Code for VS Code 제작자 Anthropic
  1. 설치가 끝나면 확장 페이지에서 자동 업데이트 체크박스를 켜둡니다. (아래 안내 참고)

7. Claude Code 실행 및 계정 연결

마지막

설치한 확장 프로그램에서 Claude Code 패널을 열고 Claude 계정으로 로그인합니다.

Claude Code 패널 열기

  1. VS Code 오른쪽 위 또는 사이드바에 생긴 Claude 아이콘을 클릭합니다.
  2. 패널이 열리지 않는다면 CtrlCmd + Shift + P를 누르고 >Claude Code: Open을 검색해 실행합니다.

Claude 계정 연결

패널이 처음 열리면 아래와 같은 로그인 화면이 표시됩니다. Claude Pro·Team·Enterprise 구독자라면 맨 위 주황색 Claude.ai Subscription 버튼을 누르세요.
