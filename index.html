Claude Code 설치 가이드

VS Code에서 Claude Code를 실행하기 위한 단계별 설정 안내입니다.

시작 전, 이 도구들이 뭔가요?

핵심은 VS Code + Claude Code 확장 두 가지면 충분합니다. 나머지는 보조 도구로, 미리 받아두면 더 풍부하게 쓸 수 있습니다.

VS Code 필수

Microsoft의 무료 코드 에디터. Claude Code 확장 프로그램이 이 위에서 실행됩니다.

Claude Code 필수

Anthropic이 만든 AI 코딩 도구. VS Code 확장으로 설치하면 채팅창에서 코드 작성·수정·실행을 맡길 수 있습니다.

Node.js 선택

자바스크립트 실행 환경. 일부 명령어·기능을 쓸 때 필요합니다. 미리 받아두면 매끄러움.

Git 선택

코드 변경 이력 관리 도구. 있으면 Claude가 변경을 추적·되돌리는 기능을 함께 활용할 수 있습니다.

Python 선택

데이터 분석·자동화에서 가장 많이 쓰이는 프로그래밍 언어. 미리 설치해두면 편합니다.

1. VS Code 설치

필수

Claude Code를 실행할 코드 에디터입니다. 인스톨러(.exe) 실행 시 "Add to PATH" 옵션은 반드시 체크 후 진행해주세요.

Claude Code를 실행할 코드 에디터입니다. 다운로드 페이지에서 Apple Silicon / Intel 칩셋에 맞는 .zip 파일을 받아 압축을 풀고 Visual Studio Code.app을 Applications 폴더로 드래그하면 설치 완료입니다.

2. VS Code 환경 설정

선택 단계

한국어 언어팩과 컬러 테마를 설정하면 화면이 더 편해집니다.

한국어 언어팩 설치

  1. VS Code 왼쪽 사이드바의 확장(Extensions) 아이콘을 클릭합니다. CtrlCmd + Shift + X
  2. 검색창에 Korean을 입력합니다.
  3. 아래와 같은 항목을 찾아 Install 버튼을 누릅니다.
Korean Language Pack for Visual Studio Code 제작자 Microsoft
  1. 오른쪽 아래 안내에 따라 Restart를 눌러 VS Code를 다시 시작합니다.

컬러 테마 변경

  1. VS Code 상단 가운데 검색창을 클릭하거나 CtrlCmd + Shift + P를 누릅니다.
  2. 검색창에 >color theme를 입력하고 기본 설정: 색 테마(Preferences: Color Theme)를 선택합니다.
  3. 방향키 ↑↓로 미리보기를 확인하고 마음에 드는 테마에서 Enter를 눌러 적용합니다.

4. Claude Code 실행 및 계정 연결

필수

설치한 확장 프로그램에서 Claude Code 패널을 열고 Claude 계정으로 로그인합니다.

Claude Code 패널 열기

  1. VS Code 오른쪽 위 또는 사이드바에 생긴 Claude 아이콘을 클릭합니다.
  2. 패널이 열리지 않는다면 CtrlCmd + Shift + P를 누르고 >Claude Code: Open을 검색해 실행합니다.

6. Git 설치

선택 단계

버전 관리를 위한 Git을 설치합니다. 아래 버튼으로 설치 파일을 받아 기본 옵션으로 설치하세요. 설치 후 명령 프롬프트에서 git --version으로 확인합니다.

macOS는 별도 설치 파일을 받을 필요 없이 Xcode Command Line Tools를 한 줄 명령어로 받는 방식이 가장 간단합니다. (Homebrew·MacPorts 등 사전 설치 불필요)

Git 다운로드 (Windows) ↗

Terminal에서 한 줄 설치

  1. Spotlight(Cmd + Space)에서 터미널 또는 Terminal을 입력해 실행합니다.
  2. 아래 명령어를 붙여 넣고 Enter를 누릅니다.
    xcode-select --install
  3. 팝업이 뜨면 설치를 누르고 약관에 동의합니다. (몇 분 소요)
  4. 설치가 끝나면 터미널에 git --version을 입력해 버전이 출력되는지 확인합니다.
참고 git-scm.com/downloads/mac 페이지에는 Homebrew·MacPorts·Binary installer 등 여러 방식이 나오지만, 일반 사용자는 위 xcode-select --install 한 줄이면 충분합니다. Homebrew를 이미 쓰고 있다면 brew install git로 최신 버전을 받는 것도 좋습니다.
